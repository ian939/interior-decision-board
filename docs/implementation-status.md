# 구현 완료 현황

- 기준일: 2026-10-06 (Asia/Seoul)
- 제품 상태: **로컬 MVP 구현 및 검증 완료**
- 출시 상태: **사용자 소유 정보 연결 대기**

## 구현된 흐름

1. 웹 또는 Telegram 개인 채팅에서 URL·파일을 등록한다.
2. 카드는 즉시 `결정 필요`에 생성되고, 로컬 Claude CLI 작업 큐가 제목·요약·출처·태그를 정리한다.
3. `확인 중`으로 이동할 때 사용자가 공간을 반드시 지정한다.
4. 두 사용자가 각자 의견과 댓글을 남기고, 보완 자료를 추가해 비교 초안을 만들 수 있다.
5. 두 사람 중 한 명이 승인할 수 있다.
6. 승인 카드를 실제 작업 문구와 함께 `반영 요청`으로 보내 공간별 목록과 Markdown/CSV로 관리한다.

## 운영 안전장치

- scrypt 비밀번호 해시와 서명된 세션 토큰
- 허용된 두 Telegram 사용자 ID만 처리
- URL 수집 시 사설망 주소 차단, 리다이렉트·크기·시간 제한
- 파일 형식·크기 제한과 서버 생성 저장 파일명
- Claude CLI 제한 모드, 도구 비활성화, 세션 미보존
- 영속 작업 큐, 최대 재시도, 서버 재시작 시 처리 중 작업 복구
- SQLite 온라인 백업과 업로드 파일 복사, 기본 최근 14개 보존
- Git에서 비밀값·DB·첨부파일·백업 제외

- 실제 표시 이름과 비밀번호의 로컬 입력

공개 저장소 `ian939/interior-decision-board`와 GitHub Pages 사이트는 생성·활성화했다. 2주 단기 운영은 도메인 구매 없이 Quick Tunnel 주소를 자동 반영한다.
